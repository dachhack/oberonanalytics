# Oberon Analytics

Static site for [oberonanalytics.ai](https://oberonanalytics.ai). One HTML file, no build step, no external dependencies. Deployed with GitHub Pages from the `main` branch root. See `DEPLOY.md` for the Pages settings and DNS records.

Currently the parody is at the root and the real site is at https://oberonanalytics.ai/real/. See DEPLOY.md to swap back.
